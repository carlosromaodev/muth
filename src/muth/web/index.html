    Os seus dados, com clareza.

    Pedimos frente e verso do documento e uma selfie apenas para esta verificação. A câmara é aberta após a sua autorização e as fotografias são enviadas quando confirmar as três capturas.

    • Antes do envio, as imagens ficam na memória desta página. Não as guardamos no armazenamento do navegador.
    • As imagens são processadas durante a verificação e não são guardadas pelo serviço. Os resultados são guardados de forma cifrada durante o período definido pelo serviço.
    • Este fluxo não autoriza o uso das suas imagens para treinar modelos.
    • Pode reiniciar a verificação para descartar as capturas e pedir a eliminação dos resultados desta sessão.

    Consulte a configuração do serviço para o prazo de conservação dos resultados.

    A nota 0–10 é indicativa. Uma fotografia, por si só, não confirma a autenticidade de um documento nem protege contra todas as formas de fraude.

    Uma captura sem complicações.

    Use o documento original, coloque-o sobre uma superfície plana e procure luz uniforme. Para a selfie, olhe directamente para a câmara.

    • Se o navegador pedir autorização, permita o acesso à câmara.
    • A câmara requer uma ligação HTTPS ou acesso por localhost.
    • Se a câmara não abrir, pode escolher uma fotografia JPEG ou PNG.
    • Revise as três imagens antes de confirmar o envio.
